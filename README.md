# X1aoZhe's OpusMC

一个在浏览器里运行的 Minecraft 复刻作品：纯 JavaScript + WebGL2 从零实现（无游戏引擎、无第三方库），
支持桌面键鼠与 iPad / 安卓平板触屏操作，画面素材来自 Minecraft 26.2 官方材质
（`tools/build_assets.py` 从 `26.2.jar` 中提取并打包）。

> 这是本项目由 [Claude Code](https://claude.com/claude-code) 生成的**第一个版本**的存档，按原样开源。

## 启动方法

```bash
git clone https://github.com/chai4918/OpusMC.git
```

1. **双击 `启动游戏.bat`**（或直接用浏览器打开 `game/index.html`）。无需安装、无需构建。
   推荐使用最新版 **Chrome / Edge**（需要 WebGL2，桌面电脑即可）。
2. 标题画面点击 **单人游戏 → 创建新的世界**，选择生存/创造模式与世界类型后进入。
3. 首次点击游戏画面会锁定鼠标；按 `Esc` 暂停并释放鼠标。
4. **iPad / 手机**：在电脑上运行 `启动游戏(本地服务器模式).bat`（需要 Python 3），iPad 与电脑连同一 Wi-Fi，
   浏览器打开 `http://<电脑局域网 IP>:8765/` 即可（服务器默认监听 `0.0.0.0:8765`）。
   首次使用如无法访问，请用管理员权限放行 TCP 8765 端口。

> 存档保存在浏览器本地（优先 IndexedDB，不可用时自动改用 localStorage；每 45 秒自动保存，退出世界时保存）。
> 若个别浏览器在 `file://` 下禁止本地存储，可改用 `启动游戏(本地服务器模式).bat`，它会在
> `http://localhost:8765/` 启动一个无缓存的本地静态服务器（同时可供局域网设备访问）。

### 云存档服务器（服务端权威存储，可选）

需要 **Node.js 22+**，零第三方依赖。双击 `启动服务器(云存档).bat`（或运行 `npm run server`），
然后打开 `http://localhost:8765/`；iPad 用 `http://<电脑局域网 IP>:8765/`。

- 世界与区块保存在 `data/mcjs.db`（SQLite），服务端是唯一权威副本
- 保存采用 **分片 stage + 原子 commit**，带 revision 冲突保护
- 标题界面会显示「云存档已连接 / 本机存档」
- 世界列表可「导入本机存档」或「切换到本机存档」；`?local=1` / `localStorage['mcjs-force-local']` 可强制本机模式
- 数据目录可用 `MC_DATA_DIR` 指定，端口用 `MC_PORT`（默认 8765，与本地静态服务器相同，二者不要同时启动）
- 每 6 小时与按 `Ctrl+C` 退出时自动备份到 `data/backup/`（保留 7 份）
- 测试：`npm test`

> 当前版本**没有账号与鉴权**，只适合可信局域网。不要直接把端口暴露到公网；
> 公网部署必须放在 HTTPS 反向代理之后，并等待账号/角色功能上线。

### 触屏 / iPad

在 iPad（iPadOS 15+，需要 WebGL2）或安卓平板上打开会自动启用触屏操作；桌面浏览器可用
`index.html?touch=1` 强制开启、`?touch=0` 强制关闭。

| 触屏操作 | 功能 |
| --- | --- |
| 左下摇杆 | 移动 |
| 拖动屏幕 | 转动视角 |
| ⛏（按住） | 挖掘方块 / 攻击生物 |
| ▣（按住） | 放置方块 / 使用物品 / 打开容器 / 吃东西 / 拉弓 |
| ▲ | 跳跃；创造模式双击切换飞行 |
| ⇩ / » | 潜行 / 疾跑（点一下切换） |
| ✈ | 创造模式飞行开关 |
| 👁 | 第一 / 第三人称视角 |
| Ⅱ / ☰ | 游戏菜单 / 物品栏 |
| ✕ | 关闭物品栏 / 箱子 / 熔炉 / 创造物品栏（界面内也有「完成」的菜单用它） |
| 点击物品栏 | 切换快捷栏格子 |
| 打开界面时 | 点击 = 左键；左上角「右」按钮切换右键模式 |

> 触屏模式下聊天与 `/` 命令暂时关闭（`game/js/touch.js` 顶部 `TOUCH_CHAT = false` 可重新开启；
> 桌面键盘玩家的聊天不受影响）。

首次启动且没有存档设置时，触屏设备默认使用 75% 渲染分辨率与 6 区块渲染距离，
可以在 选项 → 渲染分辨率 / 渲染距离 中调整。

物品栏操作与原版一致：左键拿起/放下、右键拿一半/放一个、Shift+左键快速移动、按住拖动平均分配、
双击收集同类、悬停+数字键与快捷栏交换。合成界面左侧有**配方书**，点击即可自动摆放材料（Shift+点击填充最多）。

常用命令：`/gamemode creative|survival`、`/time set day|night`、`/weather clear|rain`、`/give diamond 64`、
`/tp x y z`、`/summon zombie`、`/spawnpoint`、`/seed`、`/kill`、`/xp 100`。

## 世界生成与探索

- 无限程序化世界（16×16 区块流式加载），世界高度 256，海平面 62；可输入种子，支持**默认/超平坦**两种世界类型。
- 大陆度 / 侵蚀 / 山峰多层噪声塑造地形，河流、海洋、沙滩自然衔接。
- 12 种生物群系：平原、森林、桦木森林、针叶林、雪原、沙漠、山地、雪山、河流、海洋、冻洋、沙滩；草与树叶按温度/湿度使用官方色图平滑过渡。
- 洞穴系统（意面洞穴 + 奶酪洞穴）、地下熔岩湖、深板岩层。
- 矿脉：煤、铁、金、红石、青金石、钻石、绿宝石，含深板岩变种；花岗岩、闪长岩、安山岩团块。
- 植被：橡树、白桦、云杉、大橡树；花草、蕨、甘蔗、仙人掌、枯灌木、南瓜、蘑菇、树苗。
- 地下**地牢**与战利品箱子。
- 环境：20 分钟昼夜循环、日月与 8 种月相、星空、日出日落光晕、立体云层、雨雪天气（按群系温度区分）、水下/熔岩雾。

## 建造与方块

- 155 种可放置方块：自然方块、石材变种、木板（橡木/白桦/云杉/深色橡木/丛林/金合欢/樱花）、玻璃、羊毛、混凝土、陶瓦、石英、海晶石、海晶灯等。
- 形状与家具：台阶、楼梯、门、活板门、梯子、火把、床、箱子、熔炉、工作台、音符盒、耕地、小麦、树苗。
- 颜色：16 色羊毛、12 色染色玻璃、9 色混凝土（无染料物品，除白色羊毛外主要经创造模式或羊获取）。
- 半透明水面与染色玻璃、动态水/熔岩材质、方块破坏裂纹。
- 功能方块交互：
  - 工作台 → 3×3 合成；熔炉 → 冶炼/烹饪（燃料 + 输出槽，取出获得经验）
  - 箱子 → 存储（内容随存档保存）；门/活板门 → 开关；音符盒 → 右键演奏
  - 床 → 设置重生点、跳过夜晚；TNT → 打火石点燃，连锁爆炸并击退
  - 梯子 → 攀爬；火把/荧石/海晶灯/岩浆 → 发光
- 物理规则：沙子/沙砾受重力下落；水与熔岩按落差流动；水遇熔岩生成黑曜石/圆石；支持无限水源。
- 草方块蔓延、树叶腐烂、甘蔗/仙人掌生长、树苗长成对应树种。

## 物品、工具与装备

- **25 件工具**：木/石/铁/金/钻石 × 镐/斧/锹/剑/锄；工具类型决定能否采集，等级（木/金 0、石 1、铁 2、钻石 3）决定可挖矿物与速度；均有耐久。
- **12 件盔甲**：皮革 / 铁 / 钻石 × 头盔、胸甲、护腿、靴子，提供减伤与耐久。
- 远程/特殊：弓（蓄力拉弓）、箭、剪刀、打火石、桶 / 水桶 / 熔岩桶、骨粉。
- **17 种食物**：苹果、面包、生/熟猪牛羊肉、生/熟鸡肉、腐肉、西瓜片、曲奇、南瓜派、金苹果、烤土豆、胡萝卜；高饥饿值时自然回血。
- 材料：木棍、煤/木炭、粗铁/铁锭、粗金/金锭、钻石、绿宝石、青金石、红石、燧石、线、火药、羽毛、皮革、鸡蛋、雪球、骨头、糖、纸、书、砖等。
- 8 种刷怪蛋（创造模式）；物品堆叠上限 64。
- 创造物品栏 6 个分类：建筑方块、自然方块、功能方块、工具与战斗、食物与材料、刷怪蛋。

## 合成与冶炼

- 生存模式 2×2 合成格，工作台 3×3 合成格。
- 105 条配方（88 条有序 + 17 条无序），合成界面左侧带**配方书**：点击自动摆放材料，Shift+点击填充最多。
- 物品栏操作：左键拿起/放下、右键拿一半/放一个、Shift+左键快速移动、按住拖动平均分配、双击收集同类、悬停+数字键交换、Q 丢弃。
- 熔炉 18 条冶炼配方：矿石→锭、沙子→玻璃、圆石→石头、生肉→熟肉等，支持燃料与经验奖励。

## 生存机制

- 生命 20、饥饿 20，含饱和度与消耗；饥饿充足时自然回血，饥饿归零会持续掉血。
- 伤害来源：摔落、溺水、岩浆/着火、仙人掌、虚空、生物攻击、爆炸；带无敌帧与护甲减伤。
- 死亡掉落物品、死亡界面、在重生点（床或 `/spawnpoint`）复活。
- 挖掘时间按方块硬度、工具类型与等级计算；工具不对则不掉落。
- 经验与等级：冶炼、击杀获得经验，HUD 显示经验条与等级。
- 疾跑（消耗饥饿）、潜行（不会从方块边缘掉落）、游泳、创造模式双击空格飞行。
- 创造模式：无敌、无限方块、可飞行、无需进食。

## 农业与养殖

- 锄头翻耕地 → 种小麦种子 → 多阶段生长 → 收获小麦与种子；骨粉可催熟作物与树苗。
- 甘蔗、仙人掌自然生长；树苗长成对应树种。
- 动物繁殖：猪用胡萝卜，牛/羊用小麦，鸡用种子；幼崽随时间长大。
- 羊剪毛后吃草重新长毛；鸡下蛋、扔蛋孵化。

## 存档与多世界

- 多世界管理：创建、进入、重命名、删除；可命名、填种子、选模式（生存/创造）与世界类型。
- 存储优先级：IndexedDB → localStorage → 内存（自动降级，不阻塞启动）。
- 每 45 秒自动保存、退出世界保存、切换后台保存。
- 保存内容：方块修改、玩家位置与状态、物品栏、箱子/熔炉内容、动物、进度、世界时间与天气。
- 区块使用 RLE 压缩存储。

## 声音

- WebAudio 程序化合成：按材质区分的挖掘/放置/脚步、受伤、爆炸、引信、拾取、生物叫声、弓箭、门、溅水、进食、升级、提示音。
- 随机生成的氛围钢琴音乐；**不使用任何音频文件**。

## 界面与选项

- 全部界面使用官方 GUI 贴图与位图字体；物品图标由 3D 方块实时渲染生成。
- 第一人称手臂与手持物品；F5 切换第一/第三人称/正面视角，显示玩家模型与手持物品。
- 选项：视野、渲染距离（2–16 区块）、灵敏度、音效/音乐音量、亮度、云、视角摇晃、界面尺寸、渲染分辨率、全屏。
- HUD：快捷栏、生命/护甲/饥饿/氧气、经验条、聊天栏、进度提示、新手教程、F3 调试信息。

```
server/                         云存档服务器（Node 22，零依赖，SQLite）
data/                           服务端数据库与备份（不提交）
tools/build_assets.py           从 26.2.jar 提取并打包材质的脚本
tools/serve.py                  无缓存本地服务器
```

## 重新生成材质

`game/js/assets.js` 已随仓库提供。如需从自己的游戏文件重新生成（需要 Python 3 和 Pillow）：

```bash
pip install pillow
py tools/build_assets.py "<.minecraft>/versions/26.2/26.2.jar"
```
